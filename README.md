# 📊 Credit Card Weekly Dashboard

A real-time, interactive dashboard built to provide key insights into credit card operations using transaction and customer data. This project empowers stakeholders to monitor performance metrics, identify trends, and make informed decisions efficiently.


## 🚀 Project Overview

This dashboard was developed to address the need for timely and actionable insights into credit card usage, customer behavior, and operational performance. By connecting to a SQL database and processing raw transactional data, the dashboard delivers real-time KPIs and trend analysis in a visually compelling format.

---

## 💡 Key Features

- ✅ Real-time insights from credit card transaction and customer data
- 📈 Interactive visualizations for trends, KPIs, and customer segmentation
- 📤 Actionable insights shared with stakeholders to enhance decision-making

---

## 🛠️ Tech Stack

- **Data Source:** Postgres SQL (PgAdmin 4)
- **Dashboard Tool:** Power BI
- **Visualization:** Charts, KPIs, trend lines, filters for time range & customer segments
- **Report** Canva
